# Test Plan

## 1. 목적
기존 기능 회귀 방지와 신규/보안 기능 검증을 위한 테스트 항목을 정의한다.

## 2. 테스트 범위
- 기능 테스트
- 권한 테스트
- 입력 검증 테스트
- 보안 회귀 테스트
- 관리자 기능 테스트

## 4. 테스트 방법
| 유형 | 방법 |
|---|---|
| 라우트 테스트 | Flask test client 또는 requests 기반 시나리오 |
| DB 검증 | SQLite 직접 조회 |
| 권한 테스트 | 사용자/관리자/비로그인 세션 분리 |
| 채팅 테스트 | Socket.IO 클라이언트 시나리오 |
| 보안 테스트 | 비정상 입력, 토큰 누락, 권한 위조, 요청 반복 |

## 5. 실행 순서 권장
1. 기준 기능 회귀 테스트
2. 인증/권한/세션 보안 테스트
3. 신규 기능 테스트
4. 관리자 처리 흐름 테스트
5. 오류/감사 로그/운영 설정 테스트
